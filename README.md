# API de Gerenciamento de Professores

API RESTful desenvolvida em Node.js com Express para o gerenciamento de professores, turmas e disciplinas de uma instituição de ensino. Os dados são mantidos em memória durante a execução da aplicação.

---

## 🛠️ Tecnologias Utilizadas

- Node.js
- Express
- Nodemon (ambiente de desenvolvimento)
- Thunder Client (testes e requisições HTTP)
